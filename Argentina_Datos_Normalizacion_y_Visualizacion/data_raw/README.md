# Data Raw

Este directorio contiene los **datasets originales descargados del INDEC (Instituto Nacional de Estadística y Censos de la República Argentina)**.  
Los archivos se almacenan aquí **sin ningún tipo de modificación**, preservando su estructura original para asegurar trazabilidad y reproducibilidad del proceso ETL.

## Contenido
- Datos oficiales provenientes del sitio web del INDEC.
- Archivos en los formatos provistos por el organismo (CSV, XLSX, etc.).
- Cada dataset incluye su nombre original o uno equivalente que respeta la nomenclatura del INDEC.

## Propósito
El objetivo de este directorio es:
- Mantener una copia fiel de los datos fuente.
- Permitir auditorías y comparación entre datos crudos y datos ya procesados.
- Servir como base para los procesos de extracción, transformación y carga (ETL).

## Origen de los datos
Los datasets fueron descargados del sitio oficial del INDEC:  
https://www.indec.gob.ar
